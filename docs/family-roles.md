# 亲友团身份与权限

目标：通过本机身份 + 邀请链接，让爸爸/妈妈做管理员，爷爷/奶奶/姥姥/姥爷以亲友身份浏览与传相册。权限叠在同步密钥之上（有密钥才能解密；角色再决定能改什么）。

## 六种身份（已定）

| 身份 | 权限 |
|------|------|
| 爸爸、妈妈 | **全部权限**：事项增删改、疫苗/体检/生长/用药、相册上传下载、设置、改宝宝资料、生成邀请等 |
| 爷爷、奶奶、姥姥、姥爷 | **可浏览**全部板块；相册可**上传、下载原片**；**不能**新建/修改/删除事项与疫苗计划、改计划日、设闹钟、改生日/宝宝名、改同步密钥与照片服务地址、清空数据 |

一期不在链接里携带同步密钥；密钥仍由爸妈另行告知或已在本机配置。

## 与同步密钥的关系

- 全家仍可共用一把同步密钥（解密云端事项、生长、相册元数据）。
- **永不把同步密钥写进邀请 URL 或公开页。**
- 权限是本机 UI 强制；二期再做服务端成员表、吊销、受限令牌。

## 邀请链接

示例：

`https://lj-lioo.github.io/baby-record/#/join?role=爷爷&exp=…&sig=…`

- `role`：六种中文身份之一
- `exp`：过期时间戳（默认约 7 天）
- `sig`：HMAC 签名（有同步密钥时用其 HKDF 派生钥验签；无同步时一期软接受角色并 UI 强制，**二期加固**）
- 打开后写入本机 `settings.memberRole`，地址栏立刻清掉 join 参数

爸妈在 **设置 → 亲友团** 点「邀请××」复制链接。

## 本机身份

- 设置里可查看/切换当前角色（管理员可六选一）
- 首装或无角色时弹出引导（爸爸/妈妈优先）
- 老人打开设置：只看身份说明与少量无害项，无改密钥/危险入口

## 分期

1. **一期（v1.13.0，已落地）** 本机六角色、UI 权限拦截、带过期+签名的邀请链接（签名材料优先同步密钥派生；邀请不含密钥）
2. **二期** 服务端成员表、作废链接、强制验签、撤销设备；相册鉴权与角色对齐
3. **三期** 换钥吊销、只读不再下发完整密钥；按需加登录

## 原则

- 管理员操作（删事项、改生日、关同步、清空）须谨慎确认
- 本机数据可导出备份后再迁
